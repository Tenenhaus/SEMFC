# =============================================================================
# Algorithme SHEAR-ROTATION de Fu et Gao (2006)
#
# Reference :
#   T. Fu and X. Gao, "Simultaneous diagonalization with similarity
#   transformation for non-defective matrices", Proc. IEEE ICASSP 2006,
#   vol. IV, pp. 1137-1140.
#   (Les references internes du papier : Eberlein 1962 pour le cisaillement,
#    Ruhe 1968 pour la convergence quadratique.)
#
# Probleme : K matrices reelles R x R, F_n = P D_n P^{-1} + bruit.
# On cherche P telle que les P^{-1} F_n P soient le plus diagonales possible.
# Les colonnes de P (normalisees) sont les directions cherchees.
#
# Algorithme (equations numerotees comme dans le papier) :
#   A_n^(k+1) = U^T S^{-1} A_n^(k) S U            (1)
#   S = cisaillement (shear) de parametre y sur le plan (p,q)       (2)
#   U = rotation de Givens d'angle theta sur le plan (p,q)          (3)
#   - y : choisi avec la matrice A_h seule, h maximisant |d_n|      (11)
#         tanh y = (K_h - xi_h d_h) / (2 (d_h^2 + xi_h^2) + G_h)    (18)
#         avec G_h (14) et K_h (15)
#   - theta : minimise sum_n ||E_n''||_F^2 (hors diagonale)         (12)
#         tan 4 theta = 2 sum(xi' d') / sum(d'^2 - xi'^2)           (22)
#         branche retenue : celle qui verifie la condition (23)
#   - pivots (p,q) parcourus cycliquement par lignes :
#         (1,2),(1,3),...,(1,R),(2,3),...,(R-1,R) ; un cycle = un "sweep".
#
# PONDERATION (extension, NON presente dans le papier) :
#   Le papier minimise sum_n ||E_n''||_F^2 (eq. 12). Avec des poids w_n >= 0
#   on minimise sum_n w_n ||E_n''||_F^2. Concretement, quand tous les w_n = 1
#   on retrouve EXACTEMENT l'algorithme du papier, et sinon :
#     - les sommes de (22) et (23) sont ponderees par w_n ;
#     - le choix de h dans (11) maximise w_n |d_n| au lieu de |d_n|.
#   Le calcul de y (18) n'utilise que A_h, comme dans le papier.
#
# Critere renvoye : crit = sum_n w_n ||offdiag(P^{-1} F_n P)||_F^2
# Le papier ne donne pas de test d'arret : on s'arrete quand le critere varie
# relativement de moins de tol entre deux sweeps, ou quand il est nul.
# =============================================================================
